Тема: Перевантаження операторів
Виконав: Illia Basalukk, IT-31

Контрольні запитання

1. Що таке перевантаження операторів?
Перевантаження операторів — це можливість визначити поведінку стандартних операторів для власних класів за допомогою спеціальних методів.

2. Для чого використовується метод __add__?
Метод __add__ визначає поведінку оператора + для об'єктів класу.

3. Чому гроші краще зберігати в копійках, а не у float?
Тому що float може давати похибки під час обчислень із десятковими дробами. Зберігання в цілих копійках забезпечує точніші фінансові розрахунки.

4. Для чого використовуються __str__ і __repr__?
__str__ створює зручне для користувача текстове представлення об'єкта, а __repr__ — технічне представлення для розробника.

5. Що означає повернення NotImplemented?
Це повідомлення Python, що операція не підтримується для переданого типу об'єкта.

6. Для чого потрібен метод __lt__?
Метод __lt__ визначає поведінку оператора < і дозволяє сортувати об'єкти.

7. Для чого використовуються __len__, __contains__, __iter__ і __getitem__?
Вони дозволяють отримувати довжину об'єкта, перевіряти наявність елемента, перебирати елементи та звертатися до них за індексом.
