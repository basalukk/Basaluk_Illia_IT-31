Контрольні питання

1. Коли викликається __init__?
Метод __init__ автоматично викликається під час створення нового об'єкта класу. Він використовується для початкового налаштування атрибутів об'єкта.

2. Чим відрізняється _name від __name?
_name — домовленість, що атрибут призначений для внутрішнього використання. Python не забороняє до нього звертатися.
__name — атрибут із подвійним підкресленням на початку. Python змінює його ім'я, додаючи назву класу. Це називається name mangling.

3. Навіщо використовувати @property замість звичайного атрибута?
@property дозволяє контролювати читання та зміну атрибута, виконувати перевірки значень і зберігати зручний синтаксис доступу через крапку.

4. Як створити властивість лише для читання?
Потрібно оголосити властивість через @property і не створювати для неї setter. Тоді значення можна читати, але не можна змінювати через цю властивість.

5. Чому не варто покладатися на __del__ для закриття файлів?
Метод __del__ не гарантує точного часу виклику. Він може не виконатися в очікуваний момент, тому для закриття файлів краще використовувати конструкцію with open(), яка автоматично закриває файл.

Додаткові пояснення

Name mangling:
Звернення wallet.__balance викликає AttributeError, оскільки Python змінює ім'я атрибута на _Wallet__balance. Це не повний захист даних, а механізм уникнення випадкового доступу та конфліктів імен.

Деструктор:
__del__ викликається, коли об'єкт більше не має посилань і знищується. Якщо на об'єкт є декілька посилань, видалення одного з них не знищує об'єкт.
