Клас         Person    Student    GroupLeader

Student      True      True       False

Порядок MRO:
GroupLeader -> Student -> Person -> object

Пояснення:

потім у Student, далі в Person і наприкінці в object.

успадковує Student, а Student успадковує Person.

КОНТРОЛЬНІ ЗАПИТАННЯ

1. Що таке наслідування і навіщо воно потрібне?
Наслідування — це механізм, який дозволяє створювати нові класи
на основі вже існуючих. Воно потрібне для повторного використання
коду та створення ієрархії класів.

2. Навіщо викликати super().__init__() у конструкторі нащадка?
Виклик super().__init__() дозволяє виконати конструктор
батьківського класу та ініціалізувати успадковані атрибути.

3. Що таке перевизначення методу?
Перевизначення — це створення в класі-нащадку власної реалізації
методу, який уже існує в батьківському класі.

4. Що показує атрибут __mro__?
Атрибут __mro__ показує порядок класів, у якому Python шукає
методи та атрибути під час їх виклику.

5. Чому в завданні 3 не потрібно перевіряти тип об'єкта в циклі?
Тому що кожен клас має власну реалізацію monthly_cost().
Python автоматично викликає відповідний метод конкретного об'єкта.
Це називається поліморфізмом.
